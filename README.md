# About the project
This project is a simple School Management System developed using Python. It is designed to help organize and manage school information. The program stores information about students, teachers, courses, and classes. It provides an organized way to handle different parts of a school. The main goal of this project is to make school management easier and more efficient.

The system allows users to manage student and teacher information. It also includes features for organizing courses and classes. Users can add, view, update, and manage different records. All information is organized to make it easier to access and use. These features help keep school data structured and well-managed.

This project is developed as a Python programming project to practice programming skills. It helps demonstrate the use of Python in creating a practical management system. The project focuses on organizing data and managing different school records. It can also be improved by adding more features in the future. Overall, this project is a useful example of a basic school management application.

# structure

## class  school 
| property | Description |
| --- | --- |
| name | this is a school name |
| courses | this is a school courses |
| students | this is a students information |
| teachers | this is a teachers information |
### school class method
| method | Description |
| --- | --- |
| init |  this method adds the name of your school to the name property of the school class|
| add_student | adds a student from the school class |
| delete_student | removes a students from the school class |
| add_teacher | adds a teacher from the school class|
| delete teacher | removes a teacher from school class |
| load_data | loads data into the school |
|save_data | save data into the school |
